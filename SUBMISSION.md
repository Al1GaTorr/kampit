# Kampit — Skills track

Public product: **https://kampit-skills.vercel.app**

Kampit turns a personal skills plan into daily practice, a streak and weekly competitions. Try the explicitly labelled fictional demo, complete a quiz, and inspect your saved weekly history. The daily plan is separate from the 100-point ranking cap.

Email/password accounts are available without confirmation email, as chosen by the project owner for the hackathon. Sessions are verified server-side; **email ownership is not verified**. The guest demo is isolated from account data.

Acceptance evidence in `reports/`: 34 public demo HTTP requests, 31 live Auth HTTP requests using two synthetic integration accounts, and public desktop/mobile fictional-demo checks. These fixtures are not customers or traction metrics.

Prime is no-charge demonstration access, with no live billing. Writing length/basic repetition checks do not certify skill quality. SMTP delivery, password reset and browser account login are not verified. Old private Sites data was not imported.

See `README.md` for setup and tests. Environment examples are blank. Never rerun the one-shot bootstrap against the existing live database.
